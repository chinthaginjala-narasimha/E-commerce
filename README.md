## 📌 Project Overview

The **E-Commerce Sales Dashboard** is a Power BI project designed to analyze e-commerce sales performance and present key business metrics through interactive visualizations.

The dashboard helps explore sales, profit, product performance, customer purchasing patterns, and regional trends using the available dataset. It transforms raw sales data into visual reports that support business performance monitoring and data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track key performance indicators (KPIs).
- Compare product and category performance.
- Explore regional sales and profitability.
- Understand sales trends over time.
- Identify high-performing products and business segments.
- Enable interactive data exploration using filters and slicers.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard creation and visualization
- **Power Query** – Data cleaning and transformation, if used
- **DAX** – Calculated measures and KPIs, if implemented
- **Data Modeling** – Organizing data for analysis, if implemented
